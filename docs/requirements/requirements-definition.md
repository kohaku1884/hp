## 1. 目的・背景

### 背景
- 現在のホームページは、約9年前に無料のホームページサービスで作成されたもので、ほとんど更新されていない
- サービス内容や事務所の特徴が十分に伝わらず、初めて見る方にとって「どのような相談ができるのか」が分かりにくい
- 助成金のご相談は多いものの、単発で終わり、顧問契約につながっていない

### 目的
事務所の強みとサービス内容を分かりやすく伝え、新規のお問い合わせと顧問契約の獲得につなげる。

### ゴールと目標
| 項目 | 内容 |
|---|---|
| 最重要ゴール | 顧問契約の獲得（助成金のご相談から、顧問契約へつなげる） |
| 目標（公開後） | ホームページ経由のお問い合わせ：月1件程度 → 月5件程度 |
| 公開目標 | 2027年4月1日（多少のずれは可） |
| ご予算 | 35万円（税別） |

※ お問い合わせ数は目標値であり、達成をお約束するものではありません。

## 3. ターゲット

### 主なターゲット
- 従業員10〜50名ほどの中小企業の経営者・人事総務ご担当者
- 総務ご担当者が、経理・庶務と兼任しているケースがほとんど（労務の専任者はほぼいない）
- 業種：製造、運送、介護が中心

### ご相談の前の状況・お悩み
- 就業規則の見直し（従業員が10名を超えた、20〜30名に増えてルールが追いつかない）
- 助成金が使えるか知りたい（件数が最も多い）
- 労働時間・残業代まわりの不安（労働基準監督署の調査後のご相談もある）

### 対象外
- 従業員の方個人からの、お勤め先に関するご相談

## 4. 現状の課題と、サイトでの解決方針

| 課題 | 解決方針 |
|---|---|
| サービス内容・事務所の特徴が伝わらない | サービス3つ（顧問契約・助成金・就業規則）を整理し、「こんなときにご相談ください」を分かりやすく掲載 |
| 助成金のご相談が顧問契約につながらない | 助成金のご案内の中で顧問契約のメリットを伝え、お問い合わせへつなげる |
| ほとんど更新できていない | WordPressで、事務所様ご自身が管理画面から更新できる形にする |
| お問い合わせがメールアドレスの直接掲載のみ | お問い合わせフォームを新設（確認画面・自動返信つき） |
| 事務所名のメールアドレスがない | 独自ドメインを取得し、info@hikari-sr.jp を作成 |
| 強み（助成金の実績）が一目で分からない | TOPに実績の数字を表示し、事例を2〜3件掲載 |

## 5. スコープ（制作範囲）

### やること
- ページの制作：TOP／事務所案内／サービス紹介／お客様の声／よくあるご質問／お知らせ／コラム／お問い合わせ／プライバシーポリシー
- WordPressの構築（オリジナルテーマ）
- お知らせ・コラムを、管理画面から更新できる形に（更新者2名）
- お問い合わせフォーム（入力→確認→完了、自動返信メール、注意書き）
- レスポンシブ対応（スマートフォン・タブレット・PC）
- 基本的なSEO設定、表示速度の対策
- ドメイン・サーバーの契約手続きの代行（事務所名義）、メールアドレス（info@）1つの作成
- プライバシーポリシーの案の作成
- 管理画面の操作手順書の作成
- 公開後1か月間の不具合対応

### やらないこと（今回のスコープ外）
- 採用ページの作成（募集は「お知らせ」に掲載。専用ページは公開後に別途お見積もり）
- WEB予約システム・オンライン相談予約の開発
- 資料ダウンロード機能
- 多言語対応、EC（オンライン販売）機能
- ロゴの新規制作（お手元のロゴデータを使用）
- 写真撮影（フリー素材・イラストで補う）
- 公開後の継続的な記事の更新代行（別途の保守契約）
- 公開後の内容変更（完成のご確認後の変更は、別途ご相談）

### ご相談中
- 文章（原稿）の作成：当初は事務所様でご用意いただく前提でしたが、作成のご希望をいただきました。制作範囲が広がるため、進め方をご相談中です（「18. ご確認・ご相談事項」を参照）

## 7. 機能要件

### 7.1 お問い合わせフォーム
| 項目 | 必須／任意 |
|---|---|
| お名前 | 必須 |
| 会社名 | **必須** |
| メールアドレス | 必須 |
| ご相談の種類（顧問契約／助成金／就業規則／その他） | 必須 |

- 受信先：info@hikari-sr.jp
- フォームの上部に注意書きを表示：
  「本フォームは、事業主様・企業の人事労務ご担当者様のご相談窓口です。従業員の方個人からの、お勤め先に関するご相談には対応しておりません。」
- スパム対策を行う

- 「法改正のお知らせ」「事務所からのお知らせ」「募集」の3つに分類
- 募集（スタッフ募集）は、募集内容とご連絡先を記事として掲載
- 更新者：所長

### 7.3 コラム
- カテゴリ分け、投稿者の表示
- 更新者：有資格のスタッフ
- 公開時、書きためておられる3本を初期記事として掲載（ご提供いただける場合）

### 7.4 料金の表示
- サービス紹介の中に「料金の目安」として掲載し、「税別」と明記
  - 顧問契約：月3万円〜（従業員数などにより変わります）
  - 就業規則の作成：15万円〜
  - 助成金：着手金3万円＋成功報酬20%（成功報酬の算定の基準は、事務所様にご確認のうえ記載）

### 7.5 管理画面
- 更新者2名（所長・有資格スタッフ）。それぞれの担当に合わせて、触れる範囲を設定
- お知らせ、コラムのほか、料金・実績の数字を、管理画面から変更できる

## 18. ご確認・ご相談事項

### （1）文章の作成について（ご相談）
「1月末までの文章のご用意は難しい」とのご要望をいただきました。
全ページの文章案をこちらで作成することは可能ですが、当初のご依頼には含まれていない作業のため、約25時間ほどかかる見込みです。
そのため、次の2つのうち、どちらかをお選びいただく形でご相談します。

| 項目 | 案A：追加料金をいただき、公開日は予定どおり | 案B：追加料金はなし、公開日を延ばす |
|---|---|---|
| 追加料金（税別） | 55,000円 | なし |
| 公開日 | 2027年4月1日（木） | 2027年5月14日（金） |
| 文章案のご提出 | 2027年1月15日（金） | 2027年2月26日（金） |
| 文章のご確認・確定 | 1月29日（金）まで | 3月12日（金）まで |
| 備考 | 文章の作成に作業時間を確保するため | 他の制作作業と並行して進めるため、公開日が延びる |

- どちらの案でも、作成した文章案は、丸山様にご確認・修正いただきます
- ご予算35万円の変更はありません。案Aの追加料金は、別途のお見積もりです

### （2）助成金の実績の書き方について
